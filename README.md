# OS-Credexus

Credexus introduces engineers from Canada, Latin America, Europe, and Asia to Fortune 500 companies and startups that are already working.

The site is in `frontend/`.

```bash
cd frontend
npm ci
npm run dev
```

On Vercel, set the project root to `frontend`. Configure `SITE_URL`, `RESEND_API_KEY`, `RESEND_FROM`, and `CONTACT_TO_EMAIL` (hello@credexus.org). The production build does not need those secrets.
