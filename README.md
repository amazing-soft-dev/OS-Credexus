# OS-Credexus

Credexus introduces engineers from Canada, Latin America, Europe, and Asia to Fortune 500 companies and startups that are already working.

React Router 7, Vite 7, and Tailwind CSS v4.

```bash
npm ci
npm run dev
```

See `.env.example` for the contact form and Open Graph origin. On Vercel, the project root is the repository root. Configure `SITE_URL`, `RESEND_API_KEY`, `RESEND_FROM`, and `CONTACT_TO_EMAIL` (hello@credexus.org). The production build does not need those secrets.
